# 다우그룹 브랜드·프로젝트 자산

## 적용 범위

PROJECT HUB의 로컬 데모 화면에 다우그룹 브랜드와 공개 프로젝트 정보를 표시하기 위한 출처를 기록한다. 프로젝트 설명과 수치는 공개된 공식 페이지를 기준으로 하며, 실제 사업 현황·인허가·계약 정보의 원장으로 사용하지 않는다.

## 브랜드 로고

- 파일: `apps/web/public/images/dawoo-group-logo.jpg`
- 출처: 사용자가 제공한 `다우그룹 로고.jpg`
- 사용 위치: 좌측 내비게이션 브랜드 영역

## 표시 원칙

- 공식 페이지에서 확인할 수 없는 사업 공정률·완료일·담당자는 임의로 만들지 않는다.
- 대시보드의 백분율은 실제 사업 공정률이 아니라 PROJECT HUB의 문서·참여자 등록에 대한 `협업 공간 준비 상태`로 명시한다.
- 공식 프로젝트 정보로 이동하는 링크는 새 창에서 열고 `noreferrer`를 적용한다.
- 계열사 프로젝트는 이번 우선 반영 범위에서 제외하고 다우그룹 직접 프로젝트 3건만 노출한다.
